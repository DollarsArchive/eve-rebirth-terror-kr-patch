# EVE rebirth terror 한국어 패치

**EVE rebirth terror**의 비공식 한국어 번역 패치입니다.

현재 배포 버전은 **v1.1.0**이며, 스토리 대사·시스템 텍스트·한글 표시용 폰트 및 엔딩 자막 영상이 포함되어 있습니다.

> 이 프로젝트는 팬 제작 비공식 패치이며 게임의 개발사·퍼블리셔 및 기타 권리자와 관련이 없습니다.

## 다운로드

최신 배포 파일은 GitHub **Releases**에서 받을 수 있습니다.

- [Latest Release](https://github.com/DollarsArchive/eve-rebirth-terror-kr-patch/releases/latest)

압축 파일 안의 `설명서.txt`를 먼저 읽고 적용해 주세요.

## 적용 방식

이 패치는 원본 NSP를 수정하거나 재패키징하지 않습니다.

사용자가 직접 보유한 Base / Update NSP를 선택하면 패처가 원본을 검증한 뒤 필요한 파일에만 xdelta 패치를 적용하여 **모드용 RomFS 결과물**을 생성합니다.

간단한 순서는 다음과 같습니다.

1. 배포 ZIP을 완전히 압축 해제합니다.
2. `RUN_PATCH.cmd`를 실행합니다.
3. `RomForge 1.7.0`의 `RomForge.exe`를 선택합니다.
4. 본인이 보유한 `prod.keys`를 직접 선택합니다.
5. Base v0 NSP와 Update v131072 NSP를 선택합니다.
6. PC 또는 Switch / Android용 결과물을 생성합니다.
7. 생성된 RomFS를 사용하는 환경에 맞게 적용합니다.

Citron 및 Atmosphere의 상세 적용 경로와 오류 해결 방법은 배포 ZIP 안의 **`설명서.txt`**를 참고해 주세요.

## v1.1.0

v1.1은 기존 v1.0의 기능과 런타임 수정, 엔딩 자막을 유지하면서 최신 대사 검수 결과와 수동 수정 사항을 반영한 버전입니다.

최종 변경 대상은 총 **94개 파일**입니다.

- 스크립트 BIN 83개
- 시스템 LZS 7개
- 한글 표시용 폰트 3개
- 엔딩 자막 영상 MP4 1개

패처는 원본과 패치 결과의 해시를 검증하며, 최종 결과물에는 변경 대상 파일만 생성됩니다.

## 주의사항

- 반드시 **본인이 정당하게 보유한 게임 원본**을 사용해 주세요.
- 이 배포본에는 게임 본편, NSP/XCI/NCA, 원본 RomFS 등 게임 원본 데이터가 포함되어 있지 않습니다.
- `prod.keys`는 포함되어 있지 않으며 사용자가 직접 준비해야 합니다.
- `RomForge` 본체 역시 포함되어 있지 않습니다.
- 기존 한글패치 또는 동일 파일을 수정하는 다른 모드와 동시에 사용할 경우 충돌할 수 있습니다.
- 적용 전 기존 모드와 세이브 데이터의 백업을 권장합니다.
- 지원하지 않는 게임 버전이나 변형된 원본에 대한 적용은 보장하지 않습니다.

## 저작권 및 배포 안내

본 프로젝트는 **비영리·비상업 목적의 팬 제작 한국어 패치**입니다.

- `EVE rebirth terror` 및 관련 명칭, 상표, 캐릭터, 스토리, 원본 텍스트, 그래픽, 영상, 음원과 기타 게임 자산의 권리는 각 권리자에게 있습니다.
- 본 프로젝트는 게임의 개발사·퍼블리셔 및 기타 권리자와 제휴, 승인 또는 후원을 받은 공식 프로젝트가 아닙니다.
- 이 저장소와 배포 파일에는 게임 본편, 원본 NSP/XCI/NCA, 원본 RomFS, 복호화 키 등 배포 권한이 없는 원본 게임 데이터가 포함되어 있지 않습니다.
- 본 패치는 정식 게임을 소유한 사용자의 한국어 플레이 보조를 목적으로 배포합니다.
- 본 패치 및 이를 포함한 패키지의 **상업적 판매, 유료 배포 및 원본 게임과의 합본 재배포를 금지합니다.**
- 게임 또는 관련 권리자의 정당한 요청이 있는 경우 프로젝트의 공개 범위나 배포 방식이 변경되거나 중단될 수 있습니다.
- 패치 적용 및 사용에 따른 환경별 문제에 대해서는 사용자가 직접 백업과 복구 수단을 준비해 주세요.

## Third-party software

배포 패키지에는 패치 적용을 위해 `xdelta3`가 포함되어 있으며, 관련 라이선스 고지는 ZIP 내부 `LICENSES` 폴더에 포함되어 있습니다.

`RomForge` 및 `prod.keys`는 배포 패키지에 포함되지 않습니다.
